# Project_LMAO
LMAO: Laundromat Availability Options

Institution: Naresuan University

Advisor: Assistant Professor Dr. Wansuree Massagram

Developed with Arduino IDE using C++ language

English
======================================
  The main objective of this “Laundromat Availability Options” (LMAO) project is to focus on promoting convenience for users to better manage their time by creating an IoT device using a Node ESP32 microcontroller, an Arduino Uno R3 microcontroller, and an 801S vibration sensor module to determine whether a washing machine is in operating. The cloud-based system retrieves data from Firebase and displays it on the website. The LMAO system also sends notifications through the LINE application via LINE bot to inform users which machines are available or currently operating. Additionally, the LMAO system can track the washing machines that users are interested in and notify them when they become available. This project aims to provide researchers with an opportunity to learn about IoT computer technology and explore new business opportunities.

  Thai
  ======================================
  วัตถุประสงค์หลักของโครงการ “Laundromat Availability Options” (LMAO) นี้ คือ การส่งเสริมความสะดวกสบายให้กับผู้ใช้งานในการจัดการเวลาได้อย่างมีประสิทธิภาพมากขึ้น โดยการสร้างอุปกรณ์ IoT ที่ใช้ไมโครคอนโทรลเลอร์ Node ESP32, Arduino Uno R3 และโมดูลเซ็นเซอร์ตรวจจับแรงสั่นสะเทือน 801S เพื่อใช้ในการตรวจสอบว่าวิธีซักผ้ากำลังทำงานอยู่หรือไม่ ระบบที่ทำงานผ่านคลาวด์จะดึงข้อมูลจาก Firebase และแสดงผลบนเว็บไซต์

ระบบ LMAO ยังสามารถส่งการแจ้งเตือนผ่านแอปพลิเคชัน LINE ด้วย LINE bot เพื่อแจ้งให้ผู้ใช้ทราบว่าเครื่องซักผ้าเครื่องใดว่างหรือกำลังใช้งานอยู่ นอกจากนี้ ระบบยังสามารถติดตามเครื่องซักผ้าที่ผู้ใช้สนใจ และแจ้งเตือนเมื่อเครื่องนั้นว่าง โครงการนี้มีเป้าหมายเพื่อเปิดโอกาสให้นักวิจัยได้เรียนรู้เกี่ยวกับเทคโนโลยีคอมพิวเตอร์ IoT และสำรวจโอกาสทางธุรกิจใหม่ ๆ
